# NeoForge 1.21.1 (21.1.219)

This bundled Remake Studio generator provides a separate Minecraft 1.21.1 target pinned to NeoForge 21.1.219.

- Generator ID: `neoforge-1.21.1-21.1.219`
- Minecraft version: `1.21.1`
- NeoForge version: `21.1.219`
- Java toolchain: `21`

The generator imports the bundled `datapack-1.21.1` generator and includes the same Remake Studio AAA Particle, Fashion, and Create UI templates as the regular NeoForge 1.21.1 target.
