# Remake Studio

Remake Studio is a desktop Minecraft mod creation workspace with integrated
generators, AAA Particles, Fashion, Create UI, asset import, validation, and
release tooling.

## Run

On Windows, start the application with RUN_REMAKE_STUDIO.bat.
The direct Gradle task is runRemakeStudio.

The legacy Gradle task, internal `remark` identifiers, file formats and existing
project folder are retained for compatibility. Display branding is Remake Studio.
